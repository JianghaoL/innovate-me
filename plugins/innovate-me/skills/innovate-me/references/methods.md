# Methods: choose a lever, not a ritual

Use one method per divergent lane when it helps reveal a *new causal mechanism*. Combine methods only when the resulting search space remains understandable. These are brainstorming tools, not guarantees of originality.

| Method | Prompt to apply | Most useful when |
| --- | --- | --- |
| Assumption inversion | What if the most essential-looking component were absent, reversed, or the output became the input? | A conventional solution dominates |
| TRIZ-style contradiction | Which two desired properties seem mutually exclusive? What change removes the trade-off instead of splitting the difference? | Engineering constraints conflict |
| SCAMPER | Substitute, combine, adapt, modify, repurpose, eliminate, or reverse one important mechanism | An existing design needs mutation |
| Bisociation / distant analogy | What field solves a structurally similar problem using entirely different signals, incentives, or materials? | Search is stuck inside one domain |
| Morphological exploration | Split a system into independent dimensions (input, state, feedback, objective, scale); choose unusual combinations | Need breadth without repetition |
| Counterfactual extreme | Imagine zero latency, no screen, infinite memory, one-bit communication, or no explicit controls; bring back the most useful part | Need to escape inherited assumptions |
| Adversarial redesign | How could someone deliberately break the current design's goal? Can the failure mode become a feature? | Experiences feel predictable |
| First-principles reframe | What physical, informational, or behavioral invariant must remain, even if every implementation changes? | Algorithm or mechanism invention |

## Transfer checklist

For a cross-domain analogy, specify all four:

1. **Source mechanism:** e.g., predictive control corrects only deviations from expected dynamics.
2. **Target problem:** e.g., fast but stable audio parameter tracking.
3. **Mapping:** what is the state, observation, prediction, and feedback in the new setting?
4. **Break point:** which assumption from the source domain is likely false in the target?

An analogy without a mapping is decoration, not a new design.

## Independence and variety

- Generate lane sketches without looking back at earlier candidates when possible. If the environment supports separate independent generation, compare results only afterward; parallel agents are optional, not required.
- Intentionally vary *problem representations* (signal, system, incentive, perception, dynamics), not just named personas.
- Preserve the odd candidate until mechanism-based clustering is done. Familiarity is a useful baseline, not an automatic selection criterion.
- If three candidates can be described by the same verb-plus-object mechanism, rebuild at least one lane.
